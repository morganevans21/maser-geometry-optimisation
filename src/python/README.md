# Python Data Analysis

This directory contains the Python-based analysis and visualisation tools used to process optimisation results.

The Python component operates primarily on the data generated by the Java/COMSOL optimisation and provides statistical analysis, optimisation-performance analysis and plotting.

## Overview

The Python analysis is independent of the COMSOL simulation itself.

It is intended for:

- analysing optimisation results;
- comparing optimisation runs;
- calculating summary statistics;
- examining convergence and performance;
- generating figures;
- supporting interpretation of the optimisation data.

The analysis can therefore be performed without a COMSOL licence once the relevant result files have been generated.

## Inputs

The analysis consumes result data generated by the Java optimisation pipeline.

The current result files include:

```text
results/
├── OptimisedData.csv
├── OptimisedLogData.csv
├── WrongModeData.csv
└── Alpha.csv
```

These filenames are subject to change as the analysis pipeline is refined.

## Analysis

`data_analysis.py` performs the statistical and visual analysis of the optimisation results.

The analysis includes optimisation-performance metrics and graphical representations of the resulting data.

The script is also intended to support comparison across multiple independent optimisation runs.

As the statistical analysis is expanded, the exact analyses and generated figures should be documented alongside the corresponding code.

## Requirements

A recent Python 3 installation is required.

Python dependencies are listed in:

```text
requirements.txt
```

## Installation

Create a virtual environment if desired:

```bash
python -m venv .venv
```

Activate it and install the project dependencies:

```bash
source .venv/bin/activate
pip install -r requirements.txt
```

On Windows, activate the environment using the appropriate command for your shell.

## Running

From this directory:

```bash
python data_analysis.py
```

The script reads the relevant optimisation results and generates the configured analyses and plots.

## COMSOL Independence

The Python analysis does **not** require COMSOL itself.

Once optimisation results have been generated and exported to CSV, the analysis can be performed independently.

This makes the analysis component useful for:

* inspecting archived optimisation runs
* comparing results
* generating figures
* performing additional statistical analysis

## Reproducibility

The Python dependencies are recorded in:

```text
requirements.txt
```

The input datasets generated by the optimisation are stored separately in the repository's `results/` directory.

For reproducible analysis, use the same input dataset and dependency environment.
